# Changelog

## 0.1.0 — 2026-09-21

First public research release accompanying the NanoKMC manuscript.

Highlights:

- Active-Filtered Generic and BinaryNN solver backends for the binary FCC Kawasaki benchmark.
- Classical, Partial-Filter, Rate-Category, and Exact-Class controlled reference solvers.
- Reproducible CMake/C++17 build with an explicit paper compiler-policy option.
- Regression validation for solver invariants, rate-category limits, and documented outputs.
- Example inputs, benchmark helper, scientific provenance, citation metadata, and GitHub CI.
- Normal separate compilation with cross-compiler and sanitizer validation.
